| 夹具 | 数据与用途 |
| --- | --- |
| F-REPO | 两仓库、合法linked worktree、空仓库、非仓库、失效路径；另有shallow、partial/promisor及缺失对象样本；覆盖AC-001/003/005/009 |
| F-DATE | 沿用旧日期夹具；补自然日、IANA时区、同秒、夏令时/歧义边界和三页提交；覆盖AC-003 |
| F-TREE | A/B含新增、修改、删除、重命名、隐藏/中文/空/二进制文件及导出属性；声明/锁文件覆盖新增、删除、变更和子工作区；覆盖AC-004/005 |
| F-KEEP | 旧输出含用户修改、新增文件、node_modules、环境文件；选保留和选移除两组；构造旧/新受跟踪文件与保留根的相等/相含冲突、重复路径、缺失项及内部链接；覆盖AC-006/007 |
| F-SPECIAL | gitlink、LFS指针、符号链接、大小写碰撞、Windows保留名、越界路径；必要时直接构造Git对象，不要求Windows先能创建文件 |
| F-TXN | 已登记目标O（基于A但含用户修改）、新Git树B的暂存、逐项保留迁移日志/备份；可注入错误、强制终止、文件锁及第二实例；覆盖AC-006/007/009 |
| F-REMOTE | 本地bare远程、发布端、读取端，远程名upstream及不应更新的第二远程；覆盖AC-002 |

Git内容判据独立于导出器：用`git --no-replace-objects ls-tree -r -z --full-tree <OID>`枚举树，以二进制读取`git --no-replace-objects cat-file blob <blobOID>`，比较路径集合与字节。**保留迁移前暂存只含新Git树；迁移后最终目录等于新Git树加显式保留内容**，不含额外旧内容或Git/应用元数据。另设refs/replace夹具核对原对象语义，不能只信导出器自己的清单。
保留判据来自迁移前目标O的独立快照/清单：普通文件字节、空目录、结构及链接本身的类型/目标；不遍历链接外部目标。回滚恢复的是O全部原内容（含修改、新增及保留项），不是“还原到旧提交A”。夹具期间停止外部写进程，该判据不声称应用具备文件系统快照隔离。
源保护判据：操作前后记录HEAD、分支、索引、受跟踪/未跟踪文件字节；除主动fetch允许变化的对象/远程跟踪引用外保持一致。测试凭据使用无效哨兵字符串。

## 5. 固定目录与保留迁移故障矩阵（T-07）

前置：O是迁移前实际旧目录，包含修改/新增/保留内容；B是已校验的新Git树。每行独立重建夹具并停止外部写进程，保留迁移按根逐项记录意图、身份和结果。第一重命名指O移至备份，第二重命名指暂存提升为目标。

| 故障/取消节点 | 必须观察到的结果 |
| --- | --- |
| 生成/校验B失败：Git错误、截断、磁盘满、文件篡改、路径集合不符 | O未移动；B不成功；只可清理尚未带入用户保留内容且归属明确的暂存 |
| 旧目录首次重命名失败：权限/占用；或切换意图日志不能持久化 | O原位保留，不先删除；提示实际错误；没有日志持久化依据不进入下一破坏性步骤 |
| 逐项保留迁移前后中断，或迁移第2项失败 | 根据每项实际位置/身份逆向恢复已移动项；暂存一旦含保留内容，禁止通用“失败就删暂存”；无法恢复则保留相关目录/日志并报告recoveryRequired |
| 保留已进入暂存，但第二重命名失败 | 先从暂存归还保留项到备份，再恢复O；包含用户修改/新增的O完整。未知占位保留，不为回滚删除陌生内容 |
| 暂存已提升、COMMITTED前中断或验证/持久化失败 | 依据日志和实际身份确定新目标；需回滚时从新目标逐项回收保留内容到备份，再恢复O，不删除保留项所在新目标；不能仅凭目录存在判成功 |
| COMMITTED后删除旧备份失败 | 新目标已提交，不回滚；记录COMMITTED_CLEANUP_PENDING并释放锁，保留清理任务，允许重新加锁后下次导出；清理只能针对原事务备份 |
| 在旧目录移动、每项保留移动、提升及回滚的动作/日志间隙强制终止，再启动两次 | 每个间隙可辨识、恢复幂等；不丢O的保留内容，未知目录不猜测删除；已提交后只继续清理 |
| 生成/校验时取消；临界区或回滚时取消 | 前者O未变可cancelled；后者先收尾，新版本已提交返回success，O完整退回才cancelled，无法恢复为recoveryRequired；不得把已完成替换伪装成取消 |
| 内部junction/符号链接与外部哨兵；目标句柄占用、检测到身份/内容变化 | 清理不跟随内部链接到外部；占用/变化停止或恢复，外部哨兵不变。保留项若含链接只按冻结后的受支持规则保留链接本身，不复制外部目标；不支持时在移动O前拒绝 |

保留前源与目标内部的并发写入不具有快照隔离保证。界面须提示停止外部写进程；测试验证可检测变化的处理，不把受控夹具成功推广成“任意并发写入都安全”。

## 6. 保留路径、身份与并发（T-06/T-09）

- 保留项只接受P-07精确相对路径：中文/空格可用；拒绝绝对/盘符/UNC路径、越界`..`、通配符和流语法；规范化分隔符/大小写别名，重复及祖先/子项选择归为互不重叠的根。缺失项仅提示，不创建内容。
- 与旧或新Git跟踪文件相等、保留目录包含跟踪文件、保留项处于跟踪文件路径之下，均在移动O前拒绝；特别覆盖package.json/lock、受跟踪.env及新版本开始跟踪原保留路径。用户取消冲突保留项后才能继续，不静默覆盖/合并。
- 磁盘根、源仓库/关联worktree、Git目录、程序/配置目录及与其有包含关系的目标，未知非空目录、网络共享均按P-09拒绝；已登记但被重建的同名目录不得靠字符串认领。
- 目标及相关父路径为junction/链接，或预检后身份替换：停止且保护外部哨兵；旧目录内部链接的删除不得遍历外部目标。无创建链接权限记为未执行，不记通过。
- 两实例通过路径大小写/相对别名争用同一目标，仅一个取得锁；崩溃后先恢复未决事务。取消、回滚和失败均释放操作锁；recoveryRequired持久状态阻止普通新导出，纯清理待办不造成永久忙碌。
