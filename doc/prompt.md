## 4. 沿用规则

- 本地对象导出与手动fetch分别处理；源分支、索引、文件不变，明确允许的远程跟踪引用更新除外。
- package.json/锁文件来自所选提交；保留根为精确相对路径，不与旧/新跟踪文件重叠。无自动安装或新增保留。
- 先校验新树，再可恢复迁移；含用户保留内容的暂存不得直接清理。COMMITTED前恢复整个旧目录含用户修改；之后清理失败不回滚新版本。
- 沿用真实身份、同目标跨进程/跨state锁、NTFS/链接边界、受限清理、恢复阻断与实际取消终态。
- 瑞士风及浅色/夜间/系统三态继续保持输入和选择；原生外观限制和未测系统通知不能冒称通过。
- 写操作使用隔离夹具，旧业务目录只读；保留失败与成功证据，重现实验用新目录。
